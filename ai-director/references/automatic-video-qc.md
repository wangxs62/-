# 4.1 视频异常检测与证据驱动审片

## 工作方式
1. 收到可访问的视频后运行 `python scripts/analyze_video.py input.mp4 --out qc_output`。需要 FFmpeg/FFprobe、opencv-python、numpy。该脚本实做帧差、HSV 直方图切点候选、稠密光流运动突变、近似冻结检测，对候选区间二次加密抽帧（12fps，上限每事件50帧），输出 `anomalies.json`、`motion_metrics.csv` 和 `suspect_frames/`。
2. 检测结果只标记**可疑**时间区间。导演或具有视觉能力的 Agent 必须阅读可疑帧、视频、分镜卡、P0 产品约束和参考图，确认是否真的错误。无原始视频、参考图或模型支持时，必须明确写“无法判定”。禁止伪造模型置信度，只有可解释算法分数可作为分数显示。
3. 针对镜头切换：既定一镜到底的意外切点才是 P0/P1；预期切点不是错误。光流指标对主体移动、变焦、物体遮挡敏感，只能指示候选，不能直接把它称为相机抖动。
4. **语义检查**（人脸一致性、六视图产品结构、手部畸形、Logo/OCR）：此版未内置训练好的识别器；需视觉 Agent 有效读取参考素材并逐项对照。没有实测可用的识别器时不得声称自动识别成功。对于任一语义异常，记录参照图、具体帧与时间戳、不可变 P0 规则、主观/客观证据、误判可能性。
5. 视频中短于采样间隔的错误仍可能漏检。已抽帧不等于逐帧扫描。发现敏感区域应设置更高 sample-fps，必要时核对原视频逐帧播放。

## 审片输出结构
- 素材ID、总时长、输入参考材料与实际审查能力
- `候选异常表`: 开始/结束时间、类型、证据图片、算法指标、状态（待核实/确认/排除）
- `已确认错误表`: P0/P1/P2、违反的指定规则、时间范围、帧/视频证据、复核者、推荐处理
- `审片后剪辑方案`: 保留范围 / 删除范围 / 需重生范围 / 过渡方法 / 声音与节奏处理 / 是否需人工确认
- 最终验收应明确 `通过/建议调整/不通过/证据不足`，不要根据候选异常数量自动否决。

## 命令
```
python -m pip install -r requirements-qc.txt
python scripts/analyze_video.py input.mp4 --out review-001 --sample-fps 10
```
