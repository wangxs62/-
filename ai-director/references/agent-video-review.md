# Agent 内直接审片｜实际执行协议 4.0A

## 能力判定（先执行）
1. 有用户上传的视频且当前Agent确实能读取视频画面/时间轴：进入原视频审片。
2. 无视频读取能力，但可执行本地脚本：使用 `python scripts/extract_review_evidence.py input.mp4 --out review-evidence --interval 0.5 --max-frames 80`，再查看帧图。对运镜/音频只能做有限判断。
3. 无视频读取、无可用抽帧工具：要求用户上传关键帧或截图；状态必须是 `待审/证据不足`，不可编造审片结果。
4. 任何时候都不声称已自动调用生成平台或已看过未提供的视频。

## 输入要求
最低输入：视频或可见关键帧、用户要求/分镜；如涉及身份/产品几何，必须另有参考图或已批准设定。缺参考图的维度记 `无法判断`，不可当成通过。
每次审片建立项目ID和镜头ID，区分客户事实、导演建议与假设；不得引入案例品牌或其他客户资料。

## 审片顺序
A. 验证媒体：时长、比例、帧率、是否含音轨（仅元数据，不能证明声音质量）。
B. 对照分镜提取 P0：主体身份、产品结构、镜头起点、明确禁止事项、关键动作、画幅。
C. 按时间线建立观察记录，逐条标记 `[已观察/疑似/无法判断]`、时间码、画面位置、参考证据、预期与实际。
D. P1各0-5分：人物一致性、产品细节、运镜空间连续性、动作可信、光影一致性、分镜符合度；不适用项 N/A，不可判断项 U，不参与平均分且必须单列。
E. P0 任一明确失败 => `不通过`；P0未知 => `待人工复核`，不得自动通过；P0全部已确认通过且P1已评估项均分≥4且无重大未知 => `建议通过`；3~4 => `建议局修`；<3 => `建议重做`。评分仅为建议阈值。
F. 输出每个问题的最小修复策略：剪辑可修/局部重生成/重做镜头/需要补证据；附可复制修复提示词，不能凭空承诺模型成功率。

## 证据强度
- 仅稀疏帧：可以判断某些可见静态物体、构图；不能可靠判断帧间连续运动、镜头是否硬切、声音、快速变形。
- 原视频可播放：可审节奏与连续性，但微小商标/几何需局部放大帧证据。
- 产品/人脸一致性必须对照用户提供的同一项目参考；不可仅凭模型记忆判断。
- 自动检测和主观判断要分开写，关键客户交付需要人工终审。

## 输出模板
**项目/镜头**：...  **媒体**：...  **审查模式**：原视频/抽帧/待审
**判定**：建议通过/建议局修/建议重做/不通过/待人工复核/证据不足
**P0逐项**：约束｜结果(通过/失败/未知)｜证据
**P1逐项**：项目｜评分(0-5/N/A/U)｜依据
**问题表**：时间码｜等级｜观察证据｜偏离要求｜修复路径｜复核方式
**修复提示词**：独立可复制；明确保留不变内容和唯一修改目标
**未覆盖风险**：音频/帧间连续性/版权/细节等
**下一步**：优先级最高的一项操作
