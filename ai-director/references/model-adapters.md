# 跨模型适配器｜意图恒定、语法按核实能力转换

## 严谨声明
模型功能、时间上限、参考图数量、编辑能力和收费等级经常变化。此处**不是**2026年10月各服务的实时规格表，不提供未经核实的模型参数与成功率。用户已指定具体工具时，先使用 `assets/model-capability-checklist.md` 核对该工具当前入口；无法核实就交付模型中立版。

## 导演意图规范化（平台无关）
`Objective / InputAssets / P0Locks / CameraPath / SubjectAction / TimeBeats / ExitState / Prohibitions / Fallback`。
所有平台都保留这些信息；具体平台不支持的指令不能通过“写得更强硬”获得能力。

## Adapter步骤
1. 用户说出工具与版本（例：可灵某版本、Seedance某版本、Sora某版本、Minimax某版本）。
2. 明确本次是文生视频/图生视频/首尾帧/视频编辑；输入上限需用户界面或最新官方文档证实。
3. 是否支持首帧：支持则把稳定帧设为入口；否则用纯文字+身份图也不承诺一致。
4. 是否支持尾帧：支持则在尾帧之外描述动作路线，不期望单靠两帧保证真实中间运动。
5. 是否支持负面提示独立输入：支持可将负面项单列；否则在正文作简短约束。
6. 是否支持多图/角色/主体参考：把“身份”和“产品”分别映射到对应入口；不能映射就先合成受控首帧。
7. 是否支持局部编辑：支持则优先修关键零件；不支持则推荐稳定镜头重生成或后期合成。
8. 按当前真实时长限制分段，不能伪造15s一定可用。

## 常见工具的适配倾向（策略，不是事实规格）
| 工具家族 | 优先组织策略 | 审片重点 |
|---|---|---|
| Kling / 可灵 | 明确首帧、单主动作、空间移动与结束状态；若首尾帧功能存在则使用 | 人物面孔、手与产品、连续路径 |
| Seedance | 将分镜节拍、空间锚点和角色参考职责列清；功能按实际版本核实 | 多元素同步、长镜头空间连贯 |
| Sora | 用一段可观察的摄影描述+具体物理事件，不把镜头语言变成抽象形容词 | 时间顺序、因果和身份漂移 |
| Minimax / Hailuo | 优先清晰短镜头、单一角色动作和简单摄影路线；时长以UI为准 | 镜头失控、产品几何和节拍 |
| 其他模型 | 使用平台中立编译器，实测后形成本项目模型卡 | 本任务P0优先级 |

## A/B比较最小实验
同一首帧、同一P0、同一唯一主动作，A用较短动作+稳定机位，B用连续推进+可见视差；每版至少记录生成条件、肉眼审片分数、致命错误和返工次数。无法根据一次结果宣称哪家模型“最好”。

## Prompt差异示例
**简短模型指令版**：只写入口图、主运动、最重要产品锁、一个动作、尾态。
**详细时间轴版**：按时间节点逐段写，但禁止在每段重复矛盾的镜位。
模型是否服从按实测选择，不假设长 Prompt 一定更好。
