# 连续镜头引擎｜镜头路线、首尾帧、跨段运动

## 三种连续性，不可混淆
1. **叙事连续**：观众知道时间/空间与动作因果；可切镜。
2. **画面连续**：两个素材构图、朝向、动作对接；可能使用遮挡或剪辑。
3. **物理长镜头**：观众感觉是同一台摄像机始终在空间移动；要求视差、空间锚点和不跳跃的镜位。
如果客户明确要求“从门外连续进入室内”，必须选择第三类；除非用户允许转场，不要偷偷把路线改成多张静帧切换。

## 线路表
用一行写：`入口坐标/镜头朝向 → 路径经过的固定锚点 → 被拍到的事件 → 终点镜位/朝向/可见物 → 下一段入口`。
空间轴不明确时先给示意关系图（文字平面草图足够）：门外、保安、门槛、玄关、主厅、酒杯事件与目标人物的左右相对关系。

## 续帧协议
- 不强制抽取最后一帧；在末尾附近挑选几何最稳定、无动作模糊、主体正确、朝向明确的一帧。
- 下一段输入：上一段已确认稳定帧 + 一段极简的桥接说明（相机沿原方向继续前进，角色/家具位置不改变）+ 新动作。
- 先检查：门框数量、相机高度、主体大小、镜头轴、服装与道具姿态、光源位置、摄影机运动方向。
- 若关键人物或产品一旦被遮挡发生漂移，放弃伪长镜头，改为**经用户认可的遮挡点切镜**或镜内空镜过渡。
- 不允许把“相机从户外进入”擅改成“室内起始”，否则现有分镜首帧失效。

## 通用空间路线演示（非默认项目）
入口 A → 过渡区域 B → 前景事件 C → 深处目标 D。先依据客户实际参考图定义 A/B/C/D 坐标与彼此遮挡，计算相机是否有物理可行路径；如需要靠近 C 才能特写，重新安排事件位置或征求允许切镜。没有用户指定时，不默认任何特定建筑、人物或拍摄时长。

## 连续性日志：每段记录
- 输入图 ID 与确认为第一帧的素材；起始镜位；初始人物道具状态。
- 本段主方向与次级旋转；本段完成的事件；末段稳定候选帧时间点。
- 输出帧中门框/灯光/人物/产品位置；分辨率和裁切信息。
- 下一镜不可改变锚点；若变化则记录镜头切换理由。

## 假长镜头高风险警报
超过两个主动作（进入房间+碰杯+交谈+展示产品）或同时要求大幅前进、绕人、360°旋转、转焦、表情近景，判定为高风险：先拆事件但保留路线；目标镜头可以跨多个生成片段，不要试图用一条 prompt 规定不可实现的空间折叠。
