# 产品几何硬控｜通用商品、设备与高价值实物

## 产品结构优先于画面漂亮
此模块是对原 `brand-product-fanwork.md` 的实操补充。输入参考图不是模型绝对约束；像素级几何/Logo无法单凭 prompt 保证。品牌实拍、合成或确定性 3D 渲染仍是高精度替代方案。

## 1. 结构锁定层级
- **P0 致命不可变**：产品型号、外轮廓、整体长宽厚比例、相机模组数量/位置、按键在哪一侧、是否翻面/露屏、品牌指定文字和核心装饰纹样。
- **P1 高优先**：外壳材质、皮纹、金属拉丝方向、颜色、饰板数量、装配间隙、Logo相对位置。
- **P2 可变化**：环境反射、镜面高光轨迹、手指遮挡、自然景深和背景光斑（需在允许范围）。
- **P3 导演自由**：背景道具、环境氛围、可控光线微调。
用户给出最新明确产品参考图时，必须写每张参考图职责，不得把产品A的零件混到产品B。

## 2. 视角可见性矩阵
| 指令 | 必须锁定 | 不应该出现 |
|---|---|---|
| 只拍背面 | 镜头始终位于产品背面半空间；背部相机模组与Logo可识别 | 屏幕、正面UI、意外翻面 |
| 手拿产品侧边键 | 按键同一侧、数量与位置不变；手指触点准确 | 手指穿过边框、按键移动至对侧 |
| 放桌上拿起 | 初始接触面、握持边、手机朝向连续 | 起身瞬间“自动翻面”、机身溶解 |
| 旋转展示 | 先提供各方向参考与允许范围 | 自行生成未知侧面及新零件 |
| 极近微距 | 主体是单一零件与真实接触阴影 | 同一零件复制、多余红宝石/摄像头 |

## 3. 交互动作设计
把“手按宝石键”拆成预备→触点接触→轻微压入→回弹或保持；同镜头不要同时大幅移动手机、旋转手机、改变手势和切焦。需要红色宝石切面准确时使用按键特写且把背景动作降到最低。

## 4. 六视图检查
分别对 front/back/left/right/top/bottom 做身份校对：相机模组、功能按键、屏幕边框、厚度、饰板连接缝、上下开孔、材质是否一致。不能通过镜像左视图替代右视图，尤其左右侧功能不同。

## 5. 生成建议
1. 先作“清晰、单一背面静态英雄帧”；获批后才将人物/复杂场景加入。
2. 产品英雄帧与人物表演镜头可分开；通过剪辑匹配眼神和动作。
3. 视频中产品运动幅度小，避免大幅三轴旋转导致未知面被幻觉补完。
4. 产品面上的商标字形可在后期做跟踪贴片（用户同意）；不可假装生成结果百分百一致。

## 6. 产品可交付验收
逐项核对 P0/P1；任一 P0 不通过直接否决产品展示镜头。P1 缺陷视曝光清晰度与客户标准决定重做或局部修复。建立“参考图→裁切对比→差异位置→修复策略”问题单。

## 7. 跨品类实例化规范
为当前客户的商品建立唯一 Product ID 与结构真值表，不默认商品种类。按品类替换字段：电子设备（接口/摄像/侧键/屏幕）、腕表（表冠/表耳/盘面）、汽车（车灯/轮圈/格栅）、珠宝（镶口/爪数/石位）、美妆包装（瓶盖/标签/液面）。只对客户真实给出或参考图可辨的结构施加“必须锁定”；未知结构不得臆造。镜头禁拍的面应列入可见性矩阵；若要精确品牌字形，优先授权素材后期合成。
