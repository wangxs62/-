# 镜头编译器 4.0
每镜字段：shot_id / duration_s / aspect_ratio / narrative_purpose / first_frame / camera_start / lens_and_framing / camera_path / subject_action / environment_motion / last_frame / handoff_to_next / locked_assets / P0 / negative / fallback。
镜头先写物理轨迹：相机起点→穿越/环绕/推进的参照物→终点，明确前景/中景/背景视差；不允许只写“电影感、丝滑运镜”。
每个镜头的动作负载应与用户选择的生成策略和模型实际能力匹配。复杂镜头可以建议拆段并明确切点，但不得因制作习惯默认改成 3 秒或 5 秒。用户指定一镜到底或选择较长时长一次生成时，先指出身份、产品几何、空间与后段漂移风险，并给出可选的分段续帧方案，但不擅自改成剪切。用户选择短段生成时，必须补齐 OUT→IN 的人物姿态、产品朝向、光线、空间和动作承接。
时间预算：总时长 = 所有镜头时长 + 转场额外占用（若有）；给事件分配开始/结束秒数，最后动作可以在段末未完成，但要明确下一段承接。
连续性校验：同一人物位置/朝向/手持物/衣物/场景布局/镜头轴线在 OUT→IN 中不应无解释跳变；逐镜记录变更。
提示词编译顺序：媒介+画幅时长→相机/焦段景别→世界空间锚点→主体身份与动作→服化道/材质→光线→按秒动作→终点→连续性锁→负面项。不要将示例品牌带入当前项目。
