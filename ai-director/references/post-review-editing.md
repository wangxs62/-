# 4.1 审片后剪辑导演与可执行 EDL

审片以后必须先判断**后期是否真的能修复**。不能把同一镜头内部的结构漂移、人脸漂移、额外手指等称为“剪一下就会好”；此类问题多需局部重生、替代镜头或遮挡/裁切等明确的视觉修复。

## 剪辑决策分流
- **通过镜头**：依叙事、节奏、视线、动作接点、场景轴线选切点；默认不增加多余花哨转场。
- **单个可删除瑕疵**：若删除后动作连续、台词/声音衔接正常且不违背一镜到底要求，则可跳剪、动作匹配剪、反应镜头或B-roll遮盖；须提示观众可能察觉跳变。
- **P0产品/人脸硬错误**：若不能安全裁除，则标记重生；优先重生局部片段并保证出入帧状态匹配，不能假装普通剪辑修好。
- **镜头运动卡顿**：判断是否存在重复帧、异常运动、模型“切镜”；可尝试小幅调速/稳定，但剪辑无法恢复原本缺失的真实摄影机路径。
- **仅有开头/结尾冗余**：可直接trim，保留镜头呼吸感与动作完整性。
- **声音**：明确环境声、对白、音乐及转场策略；当前自动剪辑器仅输出无音轨画面，声音另由剪辑软件完成。

## EDL 清单
人工/导演确认后编写 JSON，例如：
```
{
  "clips": [
    {"source":"/absolute/path/source1.mp4", "start":0.0,"end":3.0,"reason":"保留建立镜头"},
    {"source":"/absolute/path/source1.mp4", "start":4.0,"end":6.0,"reason":"删除无效停顿后继续"}
  ]
}
```
默认只**生成方案**，不自动删除素材、不自动执行有损变更。`python scripts/edit_video.py edit.json --output preview.mp4` 只做预检；收到用户批准再加 `--approve` 输出视频。编辑器会重编码各剪辑片段，统一30fps，拼接成**无声** H.264 MP4；不含转场/音频/字幕/稳定/换脸/产品修复。多机位原声与精确音频处理请导入达芬奇/Premiere等NLE。

## 输出规范
1. 一页成片剪辑思路：目标平台、画幅、保留节奏、每镜起止时间。
2. 带时间码的剪辑表：源文件、in/out、预期时长、剪辑点理由、转场与音频、P0影响。
3. 可选 EDL JSON（路径用真实可访问素材，不要凭空填文件名）。
4. 若产品/人物失败，附新的生成 Prompt，区分“可剪”和“需重生”；不能未经授权执行局修。
