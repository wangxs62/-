# 审片评分与返工决策
P0 硬门槛：用户明确不能改的主体/几何/品牌/镜头起点、明显安全与授权风险、关键叙事动作、画幅；任何一项失败不得标“通过”。
P1 评分（各0-5）：主体一致性、动作物理可信、空间/时间连续性、运镜可读性、产品细节、光影一致性。P2（各0-5）：节奏、美术精致度、声音、细节装饰。未涉及项标N/A，不参与均分。
每项记录证据：时间码、画面区域、预期、实际、严重程度、修复方案；没看到视频就标“未审”，不能捏造缺陷。
决策：P0失败→局部修复或重做；P0全过且P1均分≥4→建议通过；P1均分3-4→局修；低于3→重构镜头。上述阈值为4.0建议值，可由项目合同覆盖。
失败归因顺序：输入图缺陷→任务复杂度→模型能力→运动路径→约束冲突→后期可修性。相同失败连续3次停止盲试，必须换变量并记录。
