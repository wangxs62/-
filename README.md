# AI Director Studio 4.1
这个skill可以一步一步帮助想了解AIGC视频的制作，只要说出你的想法，它就会从AIGC制作逻辑角度为你定制框架，无论是做剧本，分镜图，产品品宣视频，大胆和它交流，只要按照它提供的流程走一遍，你就可以得到一个会做AIGC的全新的自己
面向 AI 影像创作的导演工作流 Skill。它帮助创作者把一个想法逐步变成可生成、可检查、可修改的镜头方案，覆盖创意策划、分镜、提示词、连续性、审片与交付管理。

适用于广告与产品片、动画、真人短片、MV、预告片、短剧和实验影像。它面向个人创作者、小团队和没有专业影视制作经验的使用者；会根据当前素材和制作阶段给出可以直接执行的下一步。

## 能做什么

- **从创意到分镜：** 梳理故事目标、角色、场景和镜头结构，再进入图像或视频生成。
- **设计镜头语言：** 明确景别、机位、主体动作、摄影机运动及镜头之间的衔接理由。
- **编写生成提示词：** 为文生图、图生图、文生视频和图生视频整理可执行提示词与必要约束。
- **维护连续性：** 跟踪人物外观、服装、道具、空间方向、产品结构和前后镜头状态。
- **控制品牌与产品：** 将产品参考图中的外形、图案、颜色和标识列为约束，并提示生成风险。
- **检查与修复：** 根据生成结果定位问题，提出局部修改、拆镜、首尾帧或后期处理方案。
- **管理项目：** 使用项目状态、角色/产品卡和镜头卡模板记录制作信息。

## 工作方式

Skill 会先区分已经确认的信息、合理假设和导演建议。多镜头任务先搭建镜头结构，再写生成提示词；审查结果时说明发现的问题、影响和可尝试的修复办法。生成模型可能改变细节，因此它提供的是控制与检查流程，不承诺每次生成都完全一致。

## 安装

本仓库中的 Skill 位于 [`ai-director/`](ai-director/) 目录。将整个目录复制到你所使用的 AI 助手支持的 Skills 目录，并保留 `SKILL.md`、`agents/`、`assets/` 和 `references/` 的相对结构。具体安装位置请以对应平台的 Skill 安装说明为准。

## 使用

在支持 Skills 的 AI 助手中安装后，可以直接提出具体任务，例如：

- “我想做一支 30 秒的新品水杯广告，先帮我策划镜头。”
- “根据这张分镜图写图生视频提示词，保持杯子的花纹和结构。”
- “检查这段视频里人物、道具和镜头衔接的问题，并给出修复建议。”
- “继续这个项目，先根据已有素材判断现在该做哪一步。”

描述项目目标，并提供已有的图片、视频、脚本或产品资料；缺少非关键资料时，Skill 会标明假设后继续推进。

## 文件结构

```text
├── AI导演SKILL.md              # 兼容入口说明

├── assets/                     # 镜头卡、项目状态、角色/产品模板及示例素材
└── references/                 # 镜头语言、提示词、连续性、审查等专题资料
```
